# Gemini Prompt — Local NHK Easy News Front Page

## Goal

Redesign the existing `index.html` into an **NHK News Web-inspired front page for my locally generated NHK Easy News reader**.

The page is an index/front page for the Japanese-learning articles generated by my existing local script.

**Do not link the story cards directly to NHK or NHK Easy.**

Each story card must link to the **locally generated article/reader page on my PC**. These local articles contain the Japanese article, English translation, vocabulary information, JLPT levels, and other Japanese-learning features generated by my existing script.

---

## Important: preserve the existing application

Before changing anything:

1. Inspect the existing project structure and `index.html`.
2. Understand how the current page obtains its article data.
3. Find how the existing script generates and stores the individual local article pages.
4. Determine the URL/path pattern used to access those local articles.
5. Preserve the existing article-reader functionality.
6. Do not create a separate mockup or unrelated application.
7. Modify the existing top/index page so it becomes the new front page.

The front page should use the **same local article data and URL/path structure already used by the application**.

# Story links — IMPORTANT

The front page is an **index to my local Japanese-learning articles**.

For each story:

**Front page → locally generated article → Japanese text + translation + vocabulary/JLPT information**

Do NOT do:

**Front page → nhk.or.jp**

The NHK original article is useful only as a source for identifying the story and obtaining the appropriate photograph.

The user should remain inside the local application when clicking a headline.

For example, if the existing application generates something like:

    /articles/2026-09-11/story123.html

then the front-page card should link to that local URL.

**Do not invent the URL pattern. Inspect the existing project and use its actual article-generation/linking mechanism.**

---

# Photographs

The photographs shown on the front page should correspond to the **original NHK story**, rather than screenshots or generic placeholders.

For each local article:

1. Determine which original NHK News story it corresponds to.
2. Use the appropriate lead/main photograph from that story if the existing data or script already provides/caches it.
3. If the existing script already downloads or stores article photographs, reuse those local images.
4. Prefer locally stored/cached images over remote NHK image URLs where possible.
5. Do NOT invent image URLs.
6. Do NOT substitute photographs from another news organisation.
7. Do NOT let broken external image URLs prevent the page from working.

If the existing project already has a local image directory/cache, inspect it and use that mechanism.
